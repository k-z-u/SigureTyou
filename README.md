# 時雨帳 — しぐれちょう

生成りの紙に、墨と朱で記す和風タスク帳。ビルド不要・単一 HTML ファイルで動く、ローカル完結のタスク＆スケジュール管理アプリです。

`index.html` をブラウザで開くだけで使えます。サーバーもアカウントも依存パッケージも不要。データはすべて端末内の `localStorage` に保存されます。

## 特徴

- **自然言語入力** — 「明日15時 数検の勉強 1h #勉強 !高」のように書くだけで、日付・時刻・所要時間・タグ・優先度・繰り返しを解釈してタスク化
- **5 つのビュー** — 今日 / 週 / 月 / 統計 / フォーカス
- **コマンドパレット（⌘K）** — 記す・探す・移るをキーボードだけで
- **元に戻す（⌘Z）** — 直前の操作をスナップショットから復元
- **御用聞き（秘書チャット）** — miibo API 連携でチャット形式の予定操作に対応（任意設定）
- **JSON エクスポート／インポート** — データのバックアップ・復元
- **単一ファイル** — ビルドも依存関係もゼロ。`index.html` ひとつ

## クイックスタート

```bash
open index.html
```

ブラウザでファイルを開くだけ。ローカルサーバーやビルドツールは不要です。

## 自然言語入力チートシート

入力欄に好きな形で書くと、以下が自動で解釈されます。

| カテゴリ | 記法例 | 備考 |
| --- | --- | --- |
| 相対日付 | `今日` `明日` `明後日` | |
| 絶対日付 | `8/15` `8月15日` | 過ぎた日付は翌年に繰り越し |
| 曜日指定 | `金曜` `来週月曜` `毎週金曜` | 単独の曜日は次の該当曜日 |
| 時刻 | `15時` `15時30分` `15:30` `15時半` | |
| 時間帯 | `朝` `午前` `午後` `夜` | それぞれ 8:00 / 9:00 / 14:00 / 20:00 |
| 所要時間 | `1h` `90m` `1時間半` `2時間` `45分` | |
| タグ | `#勉強` `#部活` | 複数指定可 |
| 優先度 | `!高` `!中` `!低`（`!high` 等も可） | 省略時は中 |
| 繰り返し | `毎日` `毎週金曜` | |

残ったテキストがタスク名になります。例:

```
明日15時 数検の勉強 1h #勉強 !高
→ 8/29 15:00〜16:00 · #勉強 · 優先度:高 · 「数検の勉強」
```

## ビュー

| ビュー | 内容 |
| --- | --- |
| **今日** | タイムライン表示。現在時刻ライン付き |
| **週** | カレンダー形式で週間を俯瞰 |
| **月** | 月次カレンダー |
| **統計** | 直近 16 週のヒートマップ、7 日間の完了推移、タグ別集計 |
| **フォーカス** | ポモドーロタイマーで一点集中 |

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `⌘K` | コマンドパレット（記す・探す・移る） |
| `⌘Z` | 直前の操作を取り消し |

## 秘書チャット（miibo 連携）

任意機能。有効にすると、チャット形式で予定の作成・検索・変更ができます。

`index.html` 冒頭付近の以下の定数を、自分の miibo（[api-mebo.dev](https://api-mebo.dev)）のキーに書き換えてください。

```js
const MIIBO_API_KEY = "...";
const MIIBO_AGENT_ID = "...";
```

> ⚠️ **注意** — API キーをコードに直書きしたままパブリックリポジトリへ公開すると、誰でも閲覧・悪用できる状態になります。キーはコミットせず、各自の環境で書き換えて使ってください。

## データとプライバシー

- すべてのデータはブラウザの `localStorage` にのみ保存。外部サーバーへの送信はありません（miibo 連携を有効にした場合、そのチャットでのみ API へ送信されます）
- JSON エクスポート／インポートでバックアップ・移行が可能
- ブラウザのサイトを消去するとデータも失われます

## 動作環境

- モダンブラウザ（Chrome / Safari / Edge / Firefox の最新版）
- 外部依存は Google Fonts（Shippori Mincho / Noto Sans JP）の読み込みのみ。オフラインでも機能はします（フォールバックフォント表示）
