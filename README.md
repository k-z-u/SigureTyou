# 時雨帳 — しぐれちょう

生成りの紙に、墨と朱で記す和風タスク帳。ビルド不要・単一HTMLファイルで動く、ローカル完結のタスク＆スケジュール管理アプリです。

## 特徴

- **自然言語入力** — 「明日15時 数検の勉強 1h #勉強 !高」のように書くだけで、日付・時刻・所要時間・タグ・優先度を解釈してタスク化
- **今日 / 週 / 月 / 統計 / フォーカス** の5ビュー
  - **今日**：タイムライン表示、現在時刻ライン
  - **週・月**：カレンダー形式で予定を俯瞰
  - **統計**：直近16週のヒートマップ、7日間の完了推移、タグ別集計
  - **フォーカス**：ポモドーロタイマーで一点集中
- **コマンドパレット（⌘K）** — 記す・探す・移るをキーボードだけで
- **元に戻す（⌘Z）** — 直前の操作をスナップショットから復元
- **御用聞き（秘書チャット）** — miibo API 連携でチャット形式の予定操作に対応（任意設定）
- **JSONエクスポート／インポート** — データのバックアップ・復元
- **ローカル保存** — `localStorage` にすべて保存。サーバー・アカウント登録不要

## 使い方

`index.html` をブラウザで直接開くだけで動作します。

```bash
open index.html
```

ビルドツールやサーバーは不要です。データは端末のブラウザ内（`localStorage`）にのみ保存されます。

## 秘書チャット（miibo連携）を使う場合

`index.html` 冒頭付近にある以下の定数を、自分の miibo（[api-mebo.dev](https://api-mebo.dev)）のキーに書き換えてください。

```js
const MIIBO_API_KEY = "...";
const MIIBO_AGENT_ID = "...";
```

> ⚠️ **注意**：APIキーをコードに直書きしたままパブリックリポジトリへ公開すると、誰でも閲覧・悪用できる状態になります。公開リポジトリで使う場合は、キーをコミットせず各自の環境で書き換えて使う運用を推奨します。

## 動作環境

- モダンブラウザ（Chrome / Safari / Edge 等）のみで動作
- 外部依存はGoogle Fonts（Shippori Mincho / Noto Sans JP）の読み込みのみ
